El Truck Drone Parcel Delivery Problem (TDPDP) es uno de los problemas más importantes para la entrega de productos dentro del mercado actual. El valor que puede ganarse con las entregas con drones puede mejorar de manera considerable los costos de entrega de pedidos. En este trabajo se busca hacer un análisis de cómo se ha modelado matemáticamente este problema y qué enfoques se han utilizado para poder resolverlo. Se hace un análisis de la historia de este problema y sus trabajos más importantes, además de los avances y enfoques distintos que se les ha dado al problema. Se concluye que las técnicas heurísticas son más utilizadas, junto a técnicas completas que permiten obtener una solución inicial de los problemas, y se hace énfasis en continuar el trabajo para hacer que el modelo se acerque al mundo logístico real.
