El Truck Drone Parcel Delivery Problem (TDPCP) es uno de los problemas más importantes para la entrega de productos dentro del mercado actual. El valor que puede ganarse con las entregas de drones puede mejorar de manera considerable los costos de entrega de pedidos. En este trabajo se busca hacer un análisis de como se ha modelado matemáticamente este problema y que enfoques se han utilizado para poder resolverlo. Se hace análisis de la historia de este problema y sus trabajos más importantes, además de los avances y enfoques distintos que se les ha dado al problema. Se concluye que las técnicas heuristicas son más utilizadas, junto a técnicas completas que permiten obtener una solución inicial de los problemas, y se hace enfasís en continuar el trabajo para hacer que el modelo se acerque al mundo logistico real.
